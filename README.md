# 🦞 永不断连 | Never Offline

WSL + Clash 代理环境下自动修复网络断连。

## 安装

```bash
git clone https://github.com/diyin4708-code/never-offline.git
bash never-offline/guard.sh &
```

## 检查项

- Clash 代理是否存活
- TG Bot 是否在线
- undici ProxyAgent 版本是否正确

每一分钟自动检测，发现问题自动修复。
